# Code of Conduct

DevCockpit follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be kind, assume good intent, critique code rather than people, and keep discussions on topic. Harassment, personal attacks and discriminatory language aren't tolerated in issues, pull requests, discussions or any other project space.

## Reporting

Email **harimangal.pandey@outlook.com** if someone's behaviour makes you uncomfortable. Reports are read by the maintainer and kept confidential. Responses follow the Covenant's enforcement guidelines: a private warning, then a temporary ban, then a permanent ban.
